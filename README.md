# 4WD SKATE — прошивка без веб-интерфейса

Полноприводный электроскейт: 4 мотор-колеса, у каждого свой **ODrive Pro**, управление — **ESP32-WROOM-32**,
пульт — **Flipsky VX1**. Мультирычажная подвеска, обе оси подруливают.

> **English summary.** Firmware for a 4WD electric skateboard: ESP32-WROOM-32 reads a Flipsky VX1 remote over UART and
> commands four single-axis ODrive Pro controllers (one per hub motor) over CAN (CAN Simple, 500 kbit/s) in **torque mode**.
> Features: gesture arming, neutral lock, torque ramping, signal-loss soft stop, stuck-throttle lockout, low-battery limp mode,
> per-axis auto-recovery, front/brake lights. Build with PlatformIO (`pio run -t upload`). ODrive configs live in [`odrive/`](odrive/).

Это **стабильная ветка** (рабочая версия весны 2026). Версия с Wi-Fi/веб-панелью — в репозитории
[`4WD_SKATE`](https://github.com/glyuck1/4WD_SKATE).

## Железо

| Узел | Что | Подключение |
|---|---|---|
| Контроллер | ESP32-WROOM-32 (DevKit, `board = esp32dev`) | — |
| Приводы | 4 × ODrive Pro, по одному на колесо | CAN 500 kbit/s через 3.3 V CAN-трансивер |
| Моторы | 4 мотор-колеса с датчиками Холла | к своим ODrive |
| Пульт | Flipsky VX1 (приёмник) | UART 115200 8N1 |
| Свет | Фара + стоп-сигнал (через ключи, PWM) | LEDC 5 кГц, 8 бит |
| Батарея | `BATT_CELLS = 10` в коде (10S, 42 V max) — **проверить** | шина ODrive |

### Распиновка ESP32

| GPIO | Назначение |
|---|---|
| 16 | UART2 RX ← VX1 TX |
| 17 | UART2 TX → VX1 RX |
| 21 | CAN TX → трансивер |
| 22 | CAN RX ← трансивер |
| 25 | PWM фара (LEDC ch0) |
| 26 | PWM стоп-сигнал (LEDC ch1) |

### CAN-узлы

| node_id | Колесо |
|---|---|
| 0 | FL — переднее левое |
| 1 | FR — переднее правое |
| 2 | RL — заднее левое |
| 3 | RR — заднее правое |

Конфиги и найденные расхождения между платами — в [`odrive/README.md`](odrive/README.md). **Прочитать до первой поездки.**

## Сборка и прошивка

```bash
pip install platformio
pio run                  # собрать
pio run -t upload        # прошить (ESP32 по USB)
pio device monitor       # лог 115200
```

Платформа зафиксирована на `espressif32 @ ^6` (Arduino core 2.0.x). На core 3.x функции `ledcSetup/ledcAttachPin`
удалены — без правок кода не соберётся.

## Как пользоваться

| Действие | Жест на курке VX1 |
|---|---|
| **ARM** (включить моторы) | газ до упора вперёд (>90%) → в течение 3 с до упора назад (<−90%) → отпустить в центр; весь жест < 5 с |
| Газ | курок вперёд: момент = `throttle × 2.0 Nm` на каждое колесо |
| Тормоз | курок назад при движении (> 0.2 rev/s): момент = `throttle × 1.0 Nm`. Реверса нет — на месте курок назад = 0 |
| **DISARM** | курок назад (<−80%) и держать **2 с**, скейт должен стоять |
| Сброс ошибок ODrive | держать курок назад **5 с** на месте |

После ARM газ заблокирован, пока курок не вернётся в центр (**neutral lock**).

## Логика прошивки (`src/main.cpp`)

**Состояния:** `DISARMED` → `ARMED` → (`RAMPING_DOWN`) → `DISARMED`; отдельно `FATAL_ERROR`.

| Функция | Как работает |
|---|---|
| Парсер VX1 | пакеты `0x02 len payload crc16 0x03` (формат UART-пакета VESC), команда `0x23`, положение курка — `payload[2]` (0…255, центр ~128). CRC16-CCITT (poly 0x1021, init 0) |
| Мёртвая зона | 5% вокруг центра, дальше линейно |
| Калибровка курка | читается из NVS (`skate`: `cal_ctr/cal_min/cal_max/cal_ok`). **Записи в NVS в этой версии нет** — используется линейная шкала `(raw−127)/127` |
| Рамп момента | 2 Nm/s в обе стороны (от 0 до полного газа ~1 с) |
| Потеря сигнала | нет валидного пакета 300 мс → `RAMPING_DOWN`: момент плавно в 0 со скоростью 0.5 Nm/s, затем DISARM (колёса свободны). Если сигнал вернулся раньше — снова `ARMED` |
| Залипший курок | если первый пакет после включения показывает >10% — `FATAL_ERROR`, фары стробят, нужен перезапуск |
| Limp mode | если напряжение < 35 V (3.5 V/яч.), макс. момент линейно падает до 30% к 32 V; фара «дышит» |
| Авто-восстановление оси | в ARMED, если ось вышла из closed loop: есть ошибка → `Clear_Errors`, нет → снова `CLOSED_LOOP_CONTROL` |
| CAN TX | `Set_Input_Torque` 50 Гц всем подключённым осям |
| Телеметрия | heartbeat, скорость, Iq, температура, напряжение шины — из циклических сообщений ODrive (100 мс). Ось «отключена», если heartbeat нет 2 с |
| Свет | ARMED: фара 100%, стоп-сигнал мигает 300/100 мс при торможении. DISARMED: маяк — плавная вспышка 2 с каждые 12 с. FATAL: строб 5 Гц |

### Ключевые константы

| Константа | Значение | Смысл |
|---|---|---|
| `MAX_TORQUE_FWD` | 2.0 Nm | макс. момент разгона на колесо |
| `MAX_TORQUE_BRAKE` | 1.0 Nm | макс. момент торможения на колесо |
| `TORQUE_RAMP_RATE` | 2.0 Nm/s | плавность газа |
| `EMERGENCY_RAMP_RATE` | 0.5 Nm/s | сброс момента при потере связи |
| `VX1_TIMEOUT_MS` | 300 | таймаут пульта |
| `DEADZONE` | 0.05 | мёртвая зона курка |
| `BRAKE_VEL_THRESH` | 0.2 rev/s | ниже — считаем, что стоим |
| `BATT_CELLS` | 10 | пороги limp mode: 35 V / 32 V |

## Известные проблемы / что доделать

Код в этом коммите **не менялся** относительно рабочей версии — ниже то, что найдено при ревью.

1. **ODrive FR (node 1) в режиме скорости** — с этой прошивкой не будет тянуть. См. [`odrive/README.md`](odrive/README.md).
2. **pole_pairs 7 спереди / 14 сзади** — скорости колёс считаются по-разному, тяга смещена вперёд. Проверить.
3. Калибровка курка в NVS только читается — нет процедуры записи.
4. Если ось отвалилась (нет heartbeat), ARM всё равно проходит и скейт едет на 3 колёсах без предупреждения.
   Стоит запрещать ARM, пока не видны все 4 оси.
5. При `FATAL_ERROR` вызов `disarmSystem()` выходит сразу (состояние уже FATAL), команда IDLE не уходит.
   На старте оси и так в IDLE, но порядок лучше поменять.
6. Ошибки мотора (`Get_Error`, 0x03) не читаются — видна только axis_error из heartbeat.
7. `BATT_CELLS = 10` — сверить с реальной батареей, от этого зависят пороги limp mode.
