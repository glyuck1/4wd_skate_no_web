# 4WD SKATE — прошивка без веб-интерфейса (весна 2026)

Полноприводный электроскейт: 4 колеса по 200 мм, в каждом мотор с редуктором 4.5:1, у каждого мотора свой **ODrive Pro**.
Управление — **ESP32-WROOM-32**, пульт — **Flipsky VX1**. Мультирычажная подвеска, обе оси подруливают.

> **English summary.** Spring-2026 firmware for a 4WD electric skateboard: ESP32-WROOM-32 reads a Flipsky VX1 remote over UART
> and commands four single-axis ODrive Pro controllers (one per geared in-wheel motor, 4.5:1, 200 mm wheels) over CAN
> (CAN Simple, 500 kbit/s) in **torque mode**. Gesture arming, neutral lock, torque ramping, signal-loss soft stop,
> stuck-throttle lockout, low-battery limp mode, per-axis auto-recovery, lights. Build with PlatformIO (`pio run -t upload`).
> The current firmware (October 2026: in-driver braking, hill hold, Wi-Fi/OTA, ODrive setup over CAN) lives in the private
> `4WD_SKATE` repository.

**Статус:** это рабочая версия весны 2026 (тег `v1.0`) плюс launch boost. **Актуальная прошивка** (октябрь 2026: тормоз
внутри драйверов, удержание на склоне, Wi-Fi/OTA, настройка ODrive по CAN, чёрный ящик) — в приватном репозитории
`glyuck1/4WD_SKATE`.

## Сборка и прошивка

```bash
pip install platformio
pio run                  # собрать
pio run -t upload        # прошить (ESP32 по USB)
pio device monitor       # лог 115200
```

Платформа зафиксирована на `espressif32 @ ^6` (Arduino core 2.0.x). На core 3.x функции `ledcSetup/ledcAttachPin`
удалены — без правок кода не соберётся.

## Как пользоваться

| Действие | Жест на курке VX1 |
|---|---|
| **ARM** (включить моторы) | газ до упора вперёд (>90%) → в течение 3 с до упора назад (<−90%) → отпустить в центр; весь жест < 5 с |
| Газ | курок вперёд: момент = `throttle × 4.0 Nm` на мотор с места, `× 3.0 Nm` в движении |
| Тормоз | курок назад при движении: момент = `throttle × 1.0 Nm` на мотор. Реверса нет — на месте курок назад = 0 |
| **DISARM** | курок назад (<−80%) и держать **2 с**, скейт должен стоять |
| Сброс ошибок ODrive | держать курок назад **5 с** на месте |

После ARM газ заблокирован, пока курок не вернётся в центр (**neutral lock**).

## Логика прошивки (`src/main.cpp`)

**Состояния:** `DISARMED` → `ARMED` → (`RAMPING_DOWN`) → `DISARMED`; отдельно `FATAL_ERROR`.

| Функция | Как работает |
|---|---|
| Парсер VX1 | пакеты `0x02 len payload crc16 0x03` (формат UART-пакета VESC), команда `0x23`, положение курка — `payload[2]` (0…255, центр ~128). CRC16-CCITT (poly 0x1021, init 0) |
| Мёртвая зона | 5% вокруг центра (против дребезга потенциометра), дальше линейно |
| Калибровка курка | читается из NVS (`skate`: `cal_ctr/cal_min/cal_max/cal_ok`). **Записи в NVS нет** — используется линейная шкала `(raw−127)/127` |
| Рамп момента | 4 Nm/s в обе стороны |
| Launch boost | пока все моторы медленнее 1 об/с (≈0.5 км/ч) — потолок 4 Nm на мотор, дальше 3 Nm. Сейчас в драйверах `torque_soft_max = 3 Nm`, поэтому 4 Nm фактически режется до 3 |
| Потеря сигнала | нет валидного пакета 300 мс → `RAMPING_DOWN`: момент плавно в 0 со скоростью 0.5 Nm/s, затем DISARM (колёса свободны). Если сигнал вернулся раньше — снова `ARMED` |
| Залипший курок | если первый пакет после включения показывает >10% — `FATAL_ERROR`, фары стробят, нужен перезапуск |
| Limp mode | если напряжение < 35 V (3.5 V/банка, ~25% заряда), макс. момент линейно падает до 30% к 32 V; фара «дышит» |
| Авто-восстановление оси | в ARMED, если ось вышла из closed loop: есть ошибка → `Clear_Errors`, нет → снова `CLOSED_LOOP_CONTROL` |
| CAN TX | `Set_Input_Torque` 50 Гц всем подключённым осям |
| Телеметрия | heartbeat, скорость, Iq, температура, напряжение шины — из циклических сообщений ODrive (100 мс). Ось «отключена», если heartbeat нет 2 с |
| Свет | ARMED: фара 100%, стоп-сигнал мигает 300/100 мс при торможении. DISARMED: маяк — плавная вспышка 2 с каждые 12 с. FATAL: строб 5 Гц |

### Ключевые константы

| Константа | Значение | Смысл |
|---|---|---|
| `MAX_TORQUE_FWD` | 3.0 Nm | макс. момент разгона на мотор в движении |
| `MAX_TORQUE_LAUNCH` | 4.0 Nm | макс. момент на мотор при старте с места |
| `LAUNCH_VEL_THRESH` | 1.0 об/с мотора | ≈0.5 км/ч; ниже действует `MAX_TORQUE_LAUNCH` |
| `MAX_TORQUE_BRAKE` | 1.0 Nm | макс. тормозной момент на мотор |
| `TORQUE_RAMP_RATE` | 4.0 Nm/s | плавность газа |
| `EMERGENCY_RAMP_RATE` | 0.5 Nm/s | сброс момента при потере связи |
| `VX1_TIMEOUT_MS` | 300 | таймаут пульта |
| `DEADZONE` | 0.05 | мёртвая зона курка |
| `BRAKE_VEL_THRESH` | 0.2 об/с мотора | ниже — считаем, что стоим |
| `BATT_CELLS` | 10 | пороги limp mode: 35 V / 32 V |

## Замечания

- Ток батареи на старте (колёса упёрты) мал даже при полном моменте: мотор не крутится, мощность уходит только в нагрев
  обмоток. Ориентироваться надо на момент, а не на ток батареи (замер: ~7 A от батареи при 2 Nm на мотор).
- Термодатчики моторов в ODrive выключены — не держать полный газ в упоре дольше нескольких секунд.

## Известные проблемы / что доделать

1. Калибровка курка в NVS только читается — нет процедуры записи.
2. Если ось отвалилась (нет heartbeat), ARM всё равно проходит и скейт едет на 3 колёсах без предупреждения.
3. При `FATAL_ERROR` вызов `disarmSystem()` выходит сразу (состояние уже FATAL), команда IDLE не уходит.
4. Ошибки мотора (`Get_Error`, 0x03) не читаются — видна только axis_error из heartbeat.
5. Если пульт вернулся в течение ~2 с после пропадания, скейт продолжает ехать по пришедшему положению курка —
   без проверки нейтрали.
6. Порог launch boost задан в оборотах мотора (≈0.5 км/ч), а не колеса.
